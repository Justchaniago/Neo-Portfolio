# Ambient track

Place your licensed track here as `ambient.mp3`.
Suggested export: MP3, 128–192 kbps, 44.1 or 48 kHz, stereo,
30–90 seconds with loop-ready endpoints and no leading/trailing silence.
HTML audio looping is not guaranteed sample-perfect; test the seam with the final export.

The player starts muted/off and loads on explicit activation only.
There is no substitute track. Missing assets show a retry state.
